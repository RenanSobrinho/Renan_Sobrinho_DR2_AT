# 📚 Exercícios Infnet — C# e .NET

Repositório com a resolução de 12 exercícios práticos de C#, desenvolvidos como parte das disciplinas de Fundamentos de Programação do Instituto Infnet.

O projeto é um Console Application com um menu interativo, permitindo executar qualquer um dos 12 exercícios sem precisar criar um projeto novo para cada um.

## Autor

Renan Treviso Sobrinho - Instituto Infnet - 2026

## Tecnologias Utilizadas

- .NET SDK 10.0
- C# 12
- Console Application (.NET CLI)

## Como Executar

```bash
git clone https://github.com/RenanSobrinho/Renan_Sobrinho_DR2_AT.git
cd Renan_Sobrinho_DR2_AT
dotnet build
dotnet run
